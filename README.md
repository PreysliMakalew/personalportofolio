# personalportofolio
# 🌐 Portofolio Pribadi Saya

Website portofolio interaktif yang menampilkan riwayat pendidikan, pengalaman, dan kontak saya.

## ✨ Fitur Utama
- Tampilan responsif (nyaman dibuka di HP dan Laptop).
- Animasi tombol interaktif saat di-tap/hover.
- Pilihan navigasi menu yang mudah.

## 🛠️ Teknologi yang Digunakan
- **HTML5** - Struktur halaman
- **CSS3** - Desain dan animasi responsif
- **JavaScript** - Logika dan efek interaktif

## 🚀 Cara Menjalankan Proyek
1. *Clone* atau *download* repositori ini.
2. Buka folder proyek.
3. Klik 2x pada file `index.html` untuk membuanya di browser.
